# 术语表

翻译不对，读者第一句就走了。这一篇不是词典，是**踩过的坑**。

## 讲给普通人听

| 英文 | 不要直译成 | 建议讲法 | 为什么 |
|---|---|---|---|
| stablecoin | 稳定币（对新人） | **链上的马币 / 链上的新币** | 「稳定币」对圈外人是个陌生名词，还容易联想到炒作。「链上的马币」一秒就懂 |
| digital twin | 数字孪生 | **和马币一比一挂钩** | 「数字孪生」是工业制造的词，在钱这个语境里完全不落地 |
| on-chain FX | 链上外汇 | 链上换汇 | 「外汇」听起来像银行柜台业务，「换汇」是普通人真的会说的话 |
| settlement | 结算 | 到账 | 「结算」是后台词，用户关心的是「什么时候到账」 |
| liquidity | 流动性 | 有没有人接 / 能不能换得出来 | 对非交易员，「流动性」几乎没有信息量 |

## 讲给交易员听

这一组反过来 —— 交易员就是用行话的，讲白话反而显得外行。

| 英文 | 中文 |
|---|---|
| order book | 盘口 / 订单簿 |
| maker / taker | 挂单方 / 吃单方 |
| spread | 价差 |
| slippage | 滑点 |
| basis point | **个点**（简体）/ 趴（台湾用法，简体读者不用） |
| fill | 成交 |
| inventory | 仓位 |

**「趴」是台湾说法，简体读者不一定懂，写简体就用「个点」。**
这类地区差异比字体差异更容易暴露内容是翻译来的。

## 几个 Sera 专有的

| 词 | 说明 |
|---|---|
| **gas** | 不用翻。中文圈就说 gas，翻成「燃料费」反而没人看得懂 |
| **VL / Virtual Liquidity** | 虚拟流动性。首次出现时保留英文缩写 |
| **rotor** | Sera 官方的做市 agent，专有名词不翻 |
| **MYRT / XSGD** | 马币和新币的链上代币，直接用代号 |

## 一条通用原则

**先说这东西替你做了什么，再说它叫什么。**

「一个请求就能问到马币的价，不用注册」比
「Sera 提供多币种稳定币外汇结算基础设施」有用一百倍。
