# Sera 中文开发文档

> 面向中文开发者的 Sera 链上外汇结算接口指南。
> 官方文档只有英文，这里是补上的那一份。

Sera 是一条做稳定币外汇结算的链上通道：链下撮合、链上结算，40 个稳定币覆盖 22 种法币。
官方文档在 [docs.sera.cx](https://docs.sera.cx)，全英文。这个仓库把开发者真正会卡住的地方
用中文写清楚，尤其是**公开接口怎么调**。

`built-on-sera`

## 为什么需要这一份

写这份文档的直接原因：`POST /swap/quote` 是**完全公开的接口**，不用 API key、不用注册、
不用私钥，任何人都能直接问价。但它的请求体格式**没有出现在公开文档里**，只存在于
`sera-mcp` 仓库的 TypeScript 类型定义中。

不知道格式的话，所有看起来合理的写法都会返回：

```json
{"detail": "Invalid request"}
```

我自己在这上面卡了很久。第 2 篇把完整格式写出来了。

## 文档里的数据都是实测的

所有数字都标了实测时间，不是抄官方宣传页的。链上流动性天天在变，
**看到日期比看到数字重要**。过期了就自己重新跑一遍，命令都给了。
