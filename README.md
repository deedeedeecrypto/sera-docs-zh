# Sera 中文开发文档

> 面向中文开发者的 Sera 链上外汇结算接口指南。
> 官方文档在 docs.sera.cx，这一份是它的中文伴读。

Sera 是一条做稳定币外汇结算的链上通道：链下撮合、链上结算，40 个稳定币覆盖 22 种法币。
官方英文文档在 [docs.sera.cx](https://docs.sera.cx)。这个仓库把上手最常用到的部分
用中文整理了一遍，让不习惯看英文文档的开发者也能十分钟跑起来。

`built-on-sera`

## 为什么做这一份

`POST /swap/quote` 是**完全公开的接口**：不用 API key、不用注册、不用私钥，
任何人都能直接问一个跨币种的价。这一点在外汇这个行当里很少见，
大部分渠道连看一眼报价都得先谈合同。

把字段、响应结构和调用方式用中文写清楚，是让中文开发者最快感受到这件事的办法。
类型定义可以对照 [`sera-cx/sera-mcp`](https://github.com/sera-cx/sera-mcp) 的
`src/sera/types.ts` 一起看，两边是一致的。

## 文档里的数据都是实测的

所有数字都标了实测时间。链上行情天天在变，
**看到日期比看到数字重要**。过期了就自己重新跑一遍，命令都给了。
